# Leak-localization-ML-models

Sample source code for leak localization using machine learning models.

## Overview
This repository contains sample source code and resources for detecting and localizing leaks. It is associated with published research work.

* **Research Paper:** [ScienceDirect Article](https://www.sciencedirect.com/science/article/pii/S2667305324000784)
* **Main Language:** Python (100%)

---

## Repository Structure

* **`Leak source localization/`**: Contains source code and notebooks related to localizing leak sources using stereo geophone audio.
* **`Thermal image/`**: Contains source code and notebooks related to localizing leak sources using thermal images.
* **`Leak Detection and Localization Research Paper.pdf`**: The full text of the associated research paper.
